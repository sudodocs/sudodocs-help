# CLI User Tasks

Command-line equivalents of the [SaaS Guide → User Tasks](../../saas-guide/user/index.md) that already have one. Available to any doc-team member (Writer or System Administrator), same as the dashboard tools they mirror. See [Getting Started](../getting-started.md) first if you haven't installed or logged in to the CLI yet.

| Dashboard page | CLI equivalent |
|---|---|
| [Manage Releases](../../saas-guide/user/releases.md) | [Manage Releases](releases.md) |
| [Tag work with a release and a writer](../../saas-guide/user/releases.md#tag-work-with-a-release-and-a-writer) (every tool's history list) | [Tool Items and Tags](items.md) |
| [Universal Converter](../../saas-guide/user/converter.md) | [Universal Converter](converter.md) |
| [Changelog](../../saas-guide/user/release-composer.md) | [Changelog](release-composer.md) |
| [API Readiness](../../saas-guide/user/api-readiness.md) | [API Readiness](api-readiness.md) |
| [Publish](../../saas-guide/publish/index.md) | [Publish commands](publish.md) |
| [Author mode](../../saas-guide/user/author-mode.md) | [Author mode commands](edit.md) |
| [Reviews](../../saas-guide/user/reviews.md) | [Review commands](reviews.md) |
| [Site health](../../saas-guide/publish/site-health.md) | [Site health commands](health.md) |
| [Capture](../../saas-guide/user/capture.md) and [Mermaid diagrams](../../saas-guide/user/diagram-gen.md) libraries | [Capture and diagram commands](capture-diagrams.md) |

The rest of User Tasks - DocOps Assistant, Manage Docflows' review side (approving and dismissing have [commands](items.md#approve-or-dismiss-a-docflows-suggestion)), the diagram editor, Author mode, Author mode vs. Docflows, Review and Push Docflows, and recording in [Capture](../../saas-guide/user/capture.md) - are review/editing workflows that stay browser-first for now. A few parts of them do have commands: [a capture's zoom on clicks](items.md#zoom-on-clicks-for-a-capture), and [reading a Docflows suggestion's changes](items.md#see-a-docflows-suggestions-changes). Recording itself stays in the browser: Capture is a Chrome extension plus a review dashboard, and there's no terminal equivalent of a screen recording or an annotated screenshot.
