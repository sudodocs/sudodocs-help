# SudoDocs Guides

Everything you can do in the SudoDocs web app at [app.sudodocs.com](https://app.sudodocs.com), split by who's doing it.

## Get started

- [Sign In and Create an Account](user/sign-in.md): sign in with a password, Google, or company SSO; create an organization; accept an invitation.
- [Profile & Security](user/profile-security.md): change your password and turn on two-factor authentication.

## Two ways to use SudoDocs

- **Write docs from scratch.** Have code and no documentation? [Start from code](user/start-from-code.md) drafts public documentation, one type at a time: a user guide, an admin guide, a command-line reference and an API reference.
- **Maintain an existing docs repository.** Keep a documentation repository current with Docflows, Author mode, Validate, the Changelog and Publish.

Not sure which? See [Write from scratch or maintain existing docs](user/two-ways.md).

## For administrators

Set up SudoDocs for your organization from **Admin** in the left menu.

- [Connect repositories](admin/connect-repos.md) with **Connect with GitHub** or a token.
- [Configure the Knowledge Base](admin/kb-config.md) so every draft follows your style guide.
- [Invite and manage users](admin/users.md), and set your organization's sign-in policy.
- [See all admin tasks](admin/index.md)

## Publish your docs

- [Publish your docs](publish/index.md): a hosted docs site from your repository, with an API reference, analytics, Ask AI and private docs.
- [Create a site](publish/create-a-site.md), pick a skin in the [Studio](publish/studio.md), and check it with [Validate](publish/validate.md).

## For writers

Draft, review, and ship documentation from **Home** and the left menu: see [Find your way around](user/find-your-way.md).

- [Author mode](user/author-mode.md): write and edit your docs pages in SudoDocs, with a live preview and review.
- [Reviews](user/reviews.md): comments, @mentions and outside reviewers on every tool.
- [Doc Assistant](user/chat.md): ask questions about your code and docs.
- [Releases](user/releases.md) and the [Release Dashboard](user/dashboards.md): your work and your team's, release by release.
- [Docflows](user/doc-drift.md): documentation suggestions from pull requests and Jira tickets.
- [Changelog](user/release-composer.md): every release's notes, collected from Docflows, Slack and Jira, drafted for you and pushed to your docs.
- [Helm charts](publish/helm-charts.md): check a chart and publish a Helm reference.
- [Capture](user/capture.md): turn a live product into a walkthrough, recording, or annotated screenshot.
- [See all user tasks](user/index.md)

## Automating with the CLI?

On an Enterprise plan, every admin task and most user tasks can also run from a terminal or CI/CD pipeline. See [CLI & API](../cli-guide/getting-started.md).
