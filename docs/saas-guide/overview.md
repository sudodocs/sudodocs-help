# SudoDocs Guides

Everything you can do in the SudoDocs web app at [app.sudodocs.com](https://app.sudodocs.com), split by who's doing it.

## Get started

- [Sign In and Create an Account](user/sign-in.md): sign in with a password, Google, or company SSO; create an organization; accept an invitation.
- [Profile & Security](user/profile-security.md): change your password and turn on two-factor authentication.

## For administrators

Set up SudoDocs for your organization from the Admin Dashboard.

- [Connect repositories](admin/connect-repos.md) with **Connect with GitHub** or a token.
- [Configure the Knowledge Base](admin/kb-config.md) so every draft follows your style guide.
- [Invite and manage users](admin/users.md), and set your organization's sign-in policy.
- [See all admin tasks](admin/index.md)

## For writers

Draft, review, and ship documentation from the Workspace.

- [DocOps Assistant](user/chat.md): ask questions about your code and docs.
- [Docflows](user/doc-drift.md): documentation suggestions from pull requests and Jira tickets.
- [Capture](user/capture.md): turn a live product into a walkthrough, recording, or annotated screenshot.
- [See all user tasks](user/index.md)

## Automating with the CLI?

On an Enterprise plan, every admin task and most user tasks can also run from a terminal or CI/CD pipeline. See [CLI & API](../cli-guide/getting-started.md).
