# Find your way around

Everything in SudoDocs is reached from the **left menu**. What you see depends on your role and plan: a locked item shows a **Pro** tag, and Reviewers only see **Reviews**.

## The left menu

| Group | Item | What it is |
|---|---|---|
| **Work** | **Home** | Your start page: what to continue, what waits for your review, your sites, and a quick start. |
| | **Author** | Write and edit docs pages on a work branch: [Author mode](author-mode.md). Its **Start from code** button drafts documentation from a code repository: [Start from code](start-from-code.md). |
| | **Docflows** | Documentation suggestions drafted from pull requests and Jira tickets: [Manage Docflows](doc-drift.md). |
| | **Reviews** | Everything people asked you to look at, across tools: [Reviews](reviews.md). |
| | **API Specs** | Your OpenAPI specs and Helm charts, and their checks: [API specs](../admin/api-specs.md). |
| | **Triage** | Decide many suggestions at once: see [Triage many at once](doc-drift.md#triage-many-at-once). |
| | **Release Dashboard** | All your team's work by release: [Dashboards](dashboards.md). |
| | **Changelog** | Each release's notes queue and drafts: [Changelog](release-composer.md). |
| | **Publish** | Your docs sites: [Publish your docs](../publish/index.md). |
| **Tools** | **Doc Assistant** | Ask about your code and docs: [Doc Assistant](chat.md). |
| | **Converter** | Convert between formats, or draft a reference from an API spec: [Converter](converter.md). |
| | **Diagrams** | The library of Mermaid diagrams: [Mermaid diagrams](diagram-gen.md). |
| | **Capture** | Walkthroughs, recordings, screenshots and audio: [Capture](capture.md). |
| | **Site health** | Check any public docs site: [Site health](../publish/site-health.md). |
| **Admin** | **Overview**, **AI provider**, **Repositories**, **Knowledge Base**, **Services**, **Single sign-on**, **Users**, **Roles**, **Site rules**, **Organization** | For administrators only: see [Admin tasks](../admin/index.md). |

Small numbers next to an item (for example the Docflows waiting for you) show what needs attention. **Collapse** at the bottom of the menu shrinks it to icons, and on a phone the menu opens from the menu button.

## The top bar

- **Search** finds a page or setting by name: press `/` to jump to it, use the arrow keys, then Enter.
- The **sun** button switches between light and dark. The **Light pane | Dark pane** switch changes only the left menu.
- The **bell** shows a dot when reviews are waiting for you.
- Your **name** opens the user menu: your email and organization, your credits, [Profile and security](profile-security.md), **Admin** for administrators, and **Sign out**.

## Where do I land after signing in?

System Administrators land on **Admin**, Walkthrough Auditors on **Capture**, Reviewers on **Reviews**, and everyone else on **Home**.
